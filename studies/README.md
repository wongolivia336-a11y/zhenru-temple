# HiFi v3 | 可再生构件样板

这不是文物实测复原，而是可审查、可替换、可进一步校准的**几何研究模型**。

- **网站实际使用的构件实现**：根目录 `model-fidelity.js`，由 `hall-model.js` 调用。网页运行时生成曲线栱端、承托斗、斜昂，以及分段搭接的实体筒瓦和板瓦；使用批处理网格而非数千个单独 draw calls。
- **离线 GLB 样板生成**：`studies/generate_assets.py`，依赖 `numpy`、`trimesh`、`shapely`。在相应目录运行脚本会新建 `assets/zhenru_bracket_research.glb` 和 `assets/zhenru_roof_tile_eave_research.glb`。这两件 GLB **不是网页当前加载的模型**；它们是独立的局部精度研究样板。
- **Blender 导入**：`studies/blender_import_and_save.py`，需要先运行样板生成脚本并根据实际运行目录调整输入路径；该脚本尚未在 Blender 中执行验证。

## 核心史料约束
1. 当前三间单檐歇山顶及尺寸约 13.4m × 13m：上海文旅推广网。
2. 两套不同斗栱铺作称谓：普陀区政府“单抄双下昂六铺作”，另一建筑研究文本记“四铺作单昂”。真实节点应以文物维修测绘为准。
3. 清光绪添檐与 1963—64 年修缮后的形制差异：不可视为本次建模的准确数字复原。

## 验证边界
- JS 源码语法检查通过；远程浏览器观察页面可加载三维场景。
- 未完整验证所有时间轴阶段、剖视模式、移动端真实触摸、导出 GLB 后 Blender 往返、以及最低 FPS。
- 后续需要加入切面几何封口、屋脊/戗脊准确建模、完整柱头与补间斗栱类型及测绘寸法。

## 正式验收
请使用静态 HTTP 服务打开项目，参考根目录 `README.md` 的启动说明。对比真实正面照的屋脊方向、瓦垄间距、屋角弧线，并开启“构架透视”逐组检查；记录显卡、分辨率、加载时间和 FPS。
