## 运行命令

```bash
git checkout feat/zhenru-archive-final-handoff
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

无需 npm 依赖、无打包脚本。Three.js r187 由 jsDelivr 固定版本 import map 载入；断网无法使用，未来可考虑本地化依赖与自动化测试。

## 验证限制（务必透明）

本轮开发环境不能直接克隆公网 GitHub 仓库到本地容器运行，因此没有可复核的本地浏览器截图；此后通过远程临时预览确认了大殿已真实渲染，但并未覆盖完整 UI、触控与控制台回归。静态语法检查不能替代真实 WebGL runtime QA。下一位执行者首要任务就是完成上面的浏览器检查并修正所有发现的问题。
