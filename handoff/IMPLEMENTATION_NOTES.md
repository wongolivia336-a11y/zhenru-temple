# 实施记录 / 第二轮

## 目标与保留项

任务：聚焦上海真如寺**大雄宝殿本体**，实现有空间深度的 Three.js 交互式建筑档案。照片仅作为现场史料，不做 CSS 假 3D，不将其它佛殿或塔混入同一建筑模型。

## 原型目前**已经做到**

真实的 Three.js Mesh、程序化屋面和瓦线、台基柱网、梁枋斗栱、门窗、屋架示意；视角控制；外部/室内/俯瞰/剖视/结构分解/构架透视；历史四阶段切换；构件点击证据；GLB导出；触屏与基础键盘。

## **没有做到，不得夸大**

- 没有原始实测数据：屋顶起翘、斗栱几何、门窗比例、旧木身份与元代逐柱位置仍是推定。
- 梁柱交接尚不能作为工程级结构力学模型；不是严格的斗栱榫卯复原。
- 剖视是 WebGL clipping plane，不是可以拖动的物理切割线，也不自动创建截面封口。
- 入殿漫游是相机移动，不具备完整的墙体碰撞、重力与物理步行；后续需修复相机与包络穿透。
- `GLTFExporter` 已在浏览器运行并生成有效 glTF 2.0 Blob（节点、网格、材质目录可解析）；自动化 Edge 取消了下载落盘，本机没有 Blender，因此 Blender round-trip 仍待可用环境验证。
- 现有 `styles.css` 是为保护原文件而采用的覆盖层，合适的二阶段重构可在全部视觉验收后合并样式并删除无用 CSS。

## 研究层次

**有公开依据**：真如寺1320年代线索、清光绪重修、1963—64落架大修、三间面阔约13.4米/进深约13米、16柱中10根元柱及6个旧础的数量。

**有图像/文献但缺测绘**：当前屋面大轮廓、梁架关系、清代添下檐的历史表现。

**视觉推演**：瓦件截面、屋顶几何细分、下檐的完整深度与比例、斗栱出跳尺度、门窗细部、室内摆件、逐柱年代身份等。

请不要在模型中标出“第N根为元代旧柱”等未经证实的信息。1959、1977、1996年的文保名录信息只是保护行政节点，不应作为屋顶历史形制变化使用。

## 继续工程升级的建议顺序

1. 后续在有硬件加速的桌面和真实触屏设备上复测帧率、双指缩放、手指命中面积与热量表现；本轮已在 Edge/WebGL 2 与触屏仿真中完成基础交互回归。
2. 对照官照与旧照校核**歇山顶真实几何**：正脊、垂脊、戗脊、两侧山花、屋脊与檐口折线；当前程序化模型仍有简化。
3. 清代形态与修缮阶段采用来源驱动的数据结构，不要臆造旧照片缺失的局部。
4. 适度使用 InstancedMesh / 合并重复构件网格、渲染降级、性能调试；
5. 增加 raycast 被遮挡热点过滤、移动端触摸控件尺寸、屏幕阅读器可达的构件索引；
6. 取得寺方资料或工程档案后逐件标注来源、证据类别、证据强度、图档引用。
