# 真如寺大雄宝殿现场采集站位草案

本文件是**待寺方批准后的拍摄草案**，不是已完成的现场勘察。站位只按建筑相对方位命名，没有假设殿堂的准确朝向、室内尺寸或允许进入区域。当前两张原始照片分别可观察到屋檐瓦当、夜间灯具与书画陈设；没有足够图像复原佛像、完整内檐或构件背面。

## 先联系谁

联系真如寺工作人员，并请其转介普陀区文物管理部门或历次修缮参与单位。询问：

- 是否允许室内摄影、三脚架、测距与局部近拍；允许的时间、区域和设备限制；
- 能否查看或引用 1963–64 年大修图纸、竣工记录、历史照片、构件编号和既有三维测绘；
- 佛像及供桌能否从正面与侧面拍摄，能否绕行；是否可在参拜/法事之外进场；
- 图片与生成模型能否公开展示，需不需要署名或审核。

不触碰、移动或攀爬文物与供器；不在佛像、供桌、柱础或屋面放置标尺。需要尺度时使用经工作人员同意的独立标尺、激光测距或既有测绘尺寸。

## 站位编号

```text
                    后立面
          E5 ───── E6 ───── E7
          │                   │
      E4  │   I3   I2   I4    │  E8
          │        I5         │
          E3     I1/入口       E1
                前立面
          E2（前侧斜向）    E0（正面）
```

- **外部 E0–E8：** 正面、两侧斜角、左右侧面、后侧斜角与后立面；沿可通行路线连续拍摄，别只在固定点转动手机。
- **室内 I1：** 门口中轴，记录空间全景和入口关系。
- **室内 I2：** 中轴中段，向佛像、入口和左右两侧分别取景。
- **室内 I3 / I4：** 左右侧通道，记录柱列、隔扇、梁架和侧向视线。
- **室内 I5：** 佛像与供桌正前方；只有工作人员允许时才拍侧面或背面，不跨越礼佛/供奉区域。

## 每站采什么

1. **整体一圈：** 以手机/相机 1×主摄、固定焦段和曝光为主，沿外墙或室内通道缓慢移动；相邻照片保持约 70–80% 重叠。每个方向至少让连续两张看到同一组角点、柱或窗格。
2. **高低两层：** 先在约胸口高度走一圈，再在允许范围内稍高/稍低补一圈，帮助解算檐下、柱头和台基。屋面上部无法从地面看清时，不用猜；请寺方提供既有高位照片或经批准的高位拍摄。
3. **关键细部：** 四向檐口、瓦当、正脊与垂脊、斗栱、梁枋交接、柱头/柱脚、门扇分格、题记、佛像正面、手印/衣纹/底座及供桌关系。细部加一张带尺度参照的近照和一张能定位的环境照。
4. **光线与材质：** 尽量选均匀自然光；深色梁架和室内佛像单独增加曝光包围，但保持同一组照片的焦段与白平衡记录。避开人流、晃动的旗幡、烟雾和反光玻璃。
5. **给 splat 的视频：** 另外拍缓慢、连续、有平移视差的视频路径。固定点的 360° 全景主要用于看环境，缺乏相机基线，不能单独替代多视角重建。
6. **保存原始件：** 直接从相机/手机导出原始分辨率照片与视频，保留 EXIF；不要只发微信压缩图。文件按 `外部_E0_日期_序号`、`室内_I2_日期_序号` 命名，并记录不能拍摄的区域。

## 交给重建流程的内容

- 原始照片/视频与站位记录；
- 可公开的既有平面、立面、剖面尺寸，或现场获准采集的控制点；
- 佛像和供桌多角度照片、相对尺寸与允许展示范围；
- 寺方/管理部门许可范围及署名要求；
- 若能取得：修缮记录、历史照片、逐件构件表及其来源。

先用 Meshroom 或 COLMAP 出现状网格与相机解，再对同一采集数据训练 Nerfstudio Splatfacto。网格用于 Three.js 结构检视；splat 用于照片级漫游。两个成果都要标注采集日期、覆盖范围、尺度依据和未覆盖区域。
