# 一殿三时｜真如寺大殿 Three.js 研究原型

以真如寺大殿为对象的交互式三维研究场景。建筑主体由 Three.js 程序化几何构成，不用照片替代模型，也不加载现成的粗略建筑模型。

## 运行

需要现代浏览器、WebGL 和网络访问权限（页面从 jsDelivr CDN 加载固定版本的 Three.js）。

在项目目录启动静态服务器：

    python -m http.server 8000

打开 http://localhost:8000。ES modules 不能可靠地从 file:// 页面直接载入，所以不要直接双击 HTML。

## 交互

- 鼠标左键拖动：环绕旋转；滚轮：缩放；右键拖动：平移。
- 点击“入殿”进入大殿内，可用 W/A/S/D 或屏幕方向键移动，拖动改变观察方向。
- “俯瞰”查看平面关系；“结构分解”抬升屋顶；“构架透视”隐藏屋面表层。
- 点击画面中的构件热点，查看证据和待核问题。
- 时间轴切换元代、光绪改建、1963—64年大修和现状；清代阶段显示附加檐层。
- 点击“下载 GLB”，导出当前时期的网格模型。可在 Blender 等支持 glTF 的软件中继续查看和编辑。

## 模型范围

场景包含石台基、踏步、16柱网、梁枋、斗栱意象、格栅墙、山花、屋面瓦线和室内空间提示。大殿公开平面尺寸约13.4 × 13.0米，已用于模型的平面外轮廓；山面分间按公开的中央开间尺寸布置。

这仍是程序化研究模型，不是实测模型或考古复原。柱位节距、屋顶举架与檐口曲线、斗栱尺度、室内布置、颜色和细部装饰均有推演成分。公开资料记载的10根元代柏木柱和6个元代旧柱础没有在场景中擅自定位。详见 sources.md。

## 技术

- Three.js r187，ES modules + import map
- OrbitControls 相机环绕、缩放和平移
- GLTFExporter 导出二进制 glTF（.glb）
- 无构建步骤；渲染库通过 jsDelivr 固定版本加载
