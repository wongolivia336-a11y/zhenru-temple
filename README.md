# 一殿三时｜真如寺大雄宝殿交互式建筑档案

一个以真如寺大雄宝殿为唯一主体的 Three.js 交互式建筑研究原型。它不是照片拼贴，也不是实测复原：建筑由程序化三维几何构成，现场照片仅作为观察材料；史料可确认的历史节点、照片观察与模型推演分别说明。

## 运行

项目采用原生 ES modules 与 import map，无需安装依赖或构建步骤。Three.js r187、OrbitControls 与 GLTFExporter 已随源码放在 `vendor/three/`，本地运行不依赖 CDN。

```bash
python -m http.server 8000
```

打开 [http://localhost:8000](http://localhost:8000)。请使用支持 WebGL 2 的现代桌面或移动浏览器。不要直接双击 `index.html`，因为浏览器通常会阻止 `file://` 下的 ES module 导入。

## 交互

- **外部环绕**：鼠标左键／触屏拖动旋转，滚轮或双指捏合缩放，右键拖动平移。
- **键盘观察**：先聚焦三维模型，使用方向键旋转，`+` / `-` 缩放，`Home` 重置。
- **入殿漫游**：点击“入殿”，用 `W A S D` 或屏幕方向键移动；移动会避开柱位。
- **视角**：外部、入殿、俯瞰。
- **结构**：“分层拆解”分别抬升屋面、梁架与柱网；“构架透视”隐藏屋面表层，剖视使用 WebGL 裁切。
- **构件档案**：点击屋面、梁架、斗栱、隔扇、柱网和台基热点，查看构件说明、证据状态与待核问题。
- **历史阶段**：拖动时间轴浏览元代题记（1320）、清代双檐说、1963—64年落架大修与现状。清代外扩柱列与下层檐顶呈现研究文章提出的“五间重檐说”；它不是测绘复原，且与官方旅游资料关于主体结构未变的表述存在差异。
- **导出**：下载当前可见阶段的 GLB，可在 Blender 等支持 glTF 的软件中继续检查和编辑。

## 模型范围与结构

主模型仅包含大雄宝殿本体及紧邻台基，不将寺内后期建筑或塔混入场景。程序化几何包含：

- 台基、踏步、柱础与 4 × 4 柱网；
- 略有收分的木柱、额枋、梁架、屋架与山花；
- 柱头铺作／斗栱的形态研究构件；
- 前后及两侧格栅隔扇；
- 分片曲面屋面、檐口起翘表达、瓦垄与脊线；
- 可进入的室内空间、供桌和佛像轮廓占位。佛像只用于说明空间尺度，形态、尺寸与位置尚未现场核实。

重复构件尽量复用几何与材质；屋面瓦垄采用低多边形管状几何表达。模型面阔、进深和中央开间参考公开资料；进深三间按研究文章所述约5.3、5.1、2.6米不等距组织。清代外扩柱列是研究性叠加，具体尺寸与构件关系仍需测绘资料校准。

## 史料与可信度

- **史料证实**：公开资料记载的年代节点、清代双檐改制、1963—64年落架大修、公开尺寸，以及16根柱中10根元代柏木柱、6个元代旧石柱础的数量信息。
- **照片观察**：项目提供的屋檐与室内照片只用于现场观察笔记，不作为模型贴图，也不据单张照片推导不可见结构。
- **视觉推演／待证**：柱位细分、斗栱构造、榫卯、梁架断面、屋顶举架、檐口曲线、瓦作、门窗分格、色彩与室内陈设。模型不擅自标注10根元代柱和6个旧柱础的具体位置。

来源入口与逐项建模边界见 [sources.md](./sources.md)。原始图纸、修缮档案、构件编号或现场测绘到位后，应优先校订几何与证据记录，而不是继续增加装饰细节。

开源摄影测量与高斯泼溅方案见 [重建工具路线](./handoff/RECONSTRUCTION_PIPELINE.md)；获准入场后的三脚架候选点和拍摄清单见 [现场采集站位草案](./handoff/PHOTO_CAPTURE_PLAN.md)。

## 技术

- Three.js r187（本地 ES modules + import map；MIT 许可证见 `vendor/three/LICENSE`）
- OrbitControls：相机环绕、缩放、平移
- GLTFExporter：二进制 glTF 导出
- 原生 JavaScript / CSS；无构建步骤
- `prefers-reduced-motion`、键盘焦点、键盘/触屏移动控制与 WebGL 2 启动失败提示

## 研究边界

本项目是教育与交互表达用途的程序化研究模型，不是实测模型、考古复原、文物修缮方案或寺方官方数字资产。它不应用于测绘、施工、结构安全判断或文物保护决策。公开网页信息仍应与原始档案及专业人员交叉核验。照片公开或转交第三方前，请确认图片授权。

## v5｜屋顶坡度有证据的参数化校准

对照 [上海普陀区公开报道](https://www.shpt.gov.cn/tupianxinwen/20250416/958655.html)所述约 26° 的屋面坡度，项目改用 `reconstruction/roof-parameters.mjs` 计算模型的屋脊抬升及内部研究屋架联动。浏览器访问 [参考照片对照实验台](./reconstruction/reference-review.html)，可选择本地图片，尝试18°–34° 研究坡度并刷新实际三维模型。数据没有原始测绘值及相机标定，任何试验数值均非真如寺正式测量结果。运行 `node scripts/check-roof-parameters.mjs` 检查参数一致性，后续阶段见 [v5 修订说明](./handoff/ROOF_PITCH_CALIBRATION_V5.md)。


## v6：单檐歇山屋顶的结构拓扑改造

不再把四坡庑殿式算法当成歇山顶。引入 `reconstruction/hip-gable-topology.mjs`，显式构建两个山花、两个端坡、四角翼面、四条垂脊和四条戗脊，保持实体瓦件及上一轮 26° 坡度校准。新增 `scripts/check-hip-gable-topology.mjs` 共边单元测试和实际 Chromium 验收；详细边界见 [v6 结构笔记](./handoff/HIP_GABLE_V6.md)。此模型依然不是实测文物数字复原。


## V7｜照片约束构件细化：补间斗栱、瓦当与滴水

按建筑考察资料记载的前后檐补间分布（每侧中间4朵、两次间各2朵），在原16组柱头斗栱之外新增16组独立可选的构件研究几何；并将四个檐口的瓦当、滴水改成批处理的实体三维构件（桌面每类224件、紧凑视口每类128件）。**节点形状和真实榫卯仍未测绘，不当作考证复原。** [研究图源与版权边界](./reconstruction/REFERENCE_ATLAS_V7.md) · [V7 技术交接](./handoff/COMPONENT_FIDELITY_V7.md)。


**V7 檐下细看视角**：主模型工具条新增“檐下细看”，把真实 3D 相机移动到现状前檐附近，用于近景观察补间铺作、瓦当与滴水；此视角的真实浏览器截图将保存在 CI Artifacts（`eave-brackets-closeup.png`）。


## V8 · 時间、古树和交互（研究性实验）

主场景增加可被四个历史阶段驱动的原生 Three.js 银杏（0067号古银杏，现状官方报道高约13.2m、冠幅11m；树形及种植位置为示意），1320年阶段明确保留为未证实、无树形。可切换春绿/秋黄及显隐，遵循 reduced-motion。结构控制支持0–100%连续拆解、60–180%相机观察缩放，以及构件分组侧重；独立 SVG 水墨院落关系底图不冒充测绘。详见 [自执行任务书](./handoff/V8_EXECUTION_PROMPT.md)。


## V9｜时间轴与构件说明的空间层级修正

依据用户桌面截图，移除浮动左下阶段摘要和与时间轴相撞的键盘说明，统一到单条“时期—形制—年号”时间轴；构件点击在右侧打开可关闭的档案卡，且不改写历史正文；将弹出式“分层侧重”改为四选项按钮组，防止原生 select 下拉覆盖研究工具。无需重构3D建筑。详见 `qa/VIEWER_UI_V9_AUDIT.md`。


## V10–V11｜第一人称入寺与「余温」实验

主页上的「进入寺院」进入与档案研究互不干扰的第一人称场景，可在庭院、檐下、殿内三个观察锚点之间切换。当前是基于实际 Three.js 网格的**私人参访切片**，不是实测寺院环境；檐下可主动留意斗栱约85秒，随后进入证据研究视角。详见 [V10参访边界](./qa/V10_ENTER_TEMPLE_HANDOFF.md)。

V11 增加概念庭院里本地计算的银杏落叶微扰。通过 InstancedMesh 与不记录路径的瞬时步速估算，走近时少量叶片轻微移动后缓慢静止，适配 reduced-motion；新增 `node scripts/check-leaf-presence.mjs` 和 WebGL 浏览器断言。预留的匿名 WebSocket 服务现在会**只在内存中**存放最多24条、85秒到期的构件关注事件，让自愿进入共在的后来访客短暂看到；不含来访者身份和精确行走轨迹。注意 `presence/config.js` 默认未配置任何线上 WSS，**多人共在尚未上线**，前端不会伪造在线人数或人物。

V11 经 GitHub Actions 实际 Chromium / WebGL 运行通过（[CI Run 42975895603](https://github.com/wongolivia336-a11y/zhenru-temple/actions/runs/42975895603)），真实浏览器、手机尺寸、传统档案模式与构件研究流程仍需在不同设备上继续观察。当前的庭院铺装、银杏落叶分布和周边院落均非现场测绘；更精细的佛像与寺院环境必须依据真实照片/授权素材进行，不可将示意模型当作史实。
